# 多多 · 商业地产投资测算工作台

面向非财务专业人员的商业地产投资初筛工具。当前版本为 **浏览器固定网页版**，可添加到手机主屏幕，并在首次打开后缓存到本地离线运行。

## 使用方式

1. 打开 GitHub Pages 地址。
2. 使用演示账号 `demo / demo1234`，或注册自己的本地账号。
3. 按“项目信息 → 成本参数 → 铺位数据 → 运营与税费 → 周边市场 → 分析结果”完成测算。
4. 可导出 11 个标签页的 Excel 测算表和 8 页 PPT 投资汇报。

## 功能

- 楼层均价初步测算与一铺一价精细测算
- 纯租金、纯联营扣点、保底与扣点取高
- 百货商场、奥特莱斯行业参考参数
- 电梯口、通道口、转角铺、主入口等位置条件溢价
- 商铺与竞品租金 Excel 模板及导入
- 投资构成、20 年现金流、IRR、NPV、回收期与敏感性分析
- 周边商业 POI 供给分析与竞品租金分位分析
- Excel / PPT 本地生成
- 手机桌面安装与离线缓存

## 数据与边界

- 项目、账号和测算数据只保存在当前浏览器的本地存储中，不上传到 GitHub。
- 更换手机、浏览器或清除浏览器数据后，本地项目不会自动迁移。
- 网页使用公开地图服务作为地址和市场初筛来源；正式决策应结合实地踏勘和授权市场数据库。
- 本工具用于投资初筛与方案比较，不替代可行性研究、审计、资产评估或税务鉴证。
- 市政基础设施配套费、人防易地建设费、城镇土地使用税等应按项目属地最新政策填写。
