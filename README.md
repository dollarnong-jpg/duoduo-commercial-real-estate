# 多多 · 商业地产投资测算工作台

面向非财务专业人员的商业地产投资初筛工具。当前版本为 **云端正式账号 + 浏览器本地 demo** 的固定网页版，可添加到手机主屏幕。

## 使用方式

1. 打开 GitHub Pages 地址。
2. 使用演示账号 `demo / demo1234` 体验，或注册正式账号并等待超级管理员审核。
3. 按“项目基本条件 → 建设投资 → 商铺收益 → 筹备期成本 → 运营期成本 → 税费与利润 → 资本金与回报”完成测算。
4. 可导出 23–24 个标签页的 Excel 测算表和 15 页 PPT 投资汇报。

## 功能

- 楼层均价初步测算与一铺一价精细测算
- 支持多楼栋、楼层分层录入，同一楼层号可分别归属于不同楼栋
- 一铺一价模板按“楼栋→楼层→铺位号→面积”顺序填写，支持“1栋”“负一层”“二楼”“1号楼1F”等常见写法自动识别
- 自动识别“租金单价、月租金单价、合同租金单价、保底租金”等列名，支持元/㎡/月、元/㎡/天和元/㎡/年换算
- 导入后显示全部铺位明细、租金单价、导入/自动定价标记、加权租金、月租金和年租金统计，并重建楼层汇总
- 建筑面积、实用面积和计租面积统一保留两位小数
- 项目、楼层和铺位可分别选择按建筑面积或实用面积（套内/租赁面积）计租
- 统一汇总各楼栋楼层的建筑面积、实用面积、计租面积、月租金、年租金和收入占比
- 纯租金、纯联营扣点、保底与扣点取高
- 百货商场、奥特莱斯行业参考参数
- 购物中心、百货商场、奥特莱斯三套联营行业基准，按业态提供销售基数、扣点率和保底租金常见区间
- 联营基准按项目所在地城市能级与3–5公里商业侦测评分自动修正，并明确标注“行业常规＋地区修正”而非当地品牌实测流水
- 纯租金项目仍保留联营基准作参考，切换纯扣点或保底取高时可直接使用，系统不会擅自改变当前结算方式
- 新建、旧改/存量改造、运营中、轻资产四类开发状态
- 产权状态、取得方式和物业建设/经营状态可作为项目投资与风险判断条件
- 按项目所在地、开发状态和商业形态自动带入建安、装修改造及设备参考单价
- 全站统一字号体系，侧边栏可切换标准、大、特大三档并自动记忆
- 电梯口、通道口、转角铺、主入口等位置条件溢价
- 商铺与竞品租金 Excel 模板及导入
- 可自由设置招商运营年限，系统按所选年期生成现金流、IRR、NPV、回收期和敏感性分析
- 物业管理费、商业管理费和中央空调使用费分别核算，并可分别设置不递增、每年复利、每年单利或每 N 年阶梯递增及递增率
- 中央空调使用费可按楼栋开启或关闭并设置独立单价；未开启楼栋按0核算，部分楼栋收费不影响物业费和商管费
- 一铺一价模板新增“楼栋收费设置”工作表，并支持物业管理费、商业管理费、中央空调费三项铺位覆盖单价
- 每个公式相关数据项旁可直接查看公式、计算逻辑、函数语法、调整建议和参数影响
- 网页内置可点击的函数字典，支持查看语法、项目示例和调整注意事项
- 投资收益、市场侦测、租金招商、税费和运营名词支持点击查看通俗解释、重要性和测算建议
- 分析结果和Excel新增筹备期投入、运营期经营成本、运营期税费及全周期成本汇总
- 新增建设期、筹备招商期、开业首年和运营期现金流，自动测算项目及资本金资金缺口峰值和建议启动资金
- 新增自有资本金、债务融资、杠杆倍数、项目净现金收益、资本金净收益、资本回报倍数和股权IRR
- 侧边栏提供完整商业地产名词词典
- 折旧年限、亏损结转、还款方式、退出方法和敏感性区间可直接调整
- 组织架构、岗位编制、税前应发月薪、12/13/14/15薪、个人及单位社保公积金、个人所得税、实发工资和招聘培训人员成本
- 组织架构支持“部门 → 岗位”两级维护，每个岗位单独填写编制、月薪和职责，并自动汇总部门及人员成本
- 物业工程、保安和保洁可分别选择自营、第三方常驻外包或第三方非常驻服务
- 三种物业服务模式均按岗位企业人员成本核算；第三方模式另计综合管理费，非常驻模式可设置岗位成本折算比例
- 工资采用税前应发口径：12/13/15薪影响年度应税工资，社保公积金按税前月薪×12个月计算，个税按中国综合所得七级年度超额累进税率估算
- 页面、Excel 模板及导出表均说明税前工资、个人社保、个税、员工实发、单位社保和企业人员成本的口径与公式
- 页面、输入框、Excel 和 PPT 的数值展示统一最多保留两位小数，底层计算保持原始精度
- 人员成本可选择按组织架构薪资倒推，管理团队、物业工程、保安和保洁分别汇入运营成本
- 土地租赁与物业租赁支出，可分别选择按面积单价或按月度总额计价
- 土地及物业租金支持不复递增、复利、单利、固定金额和每N年阶梯递增
- 招商费用和常规运营成本可按每个运营年度单独设置调整系数及额外成本
- 运营成本支持按项目所在地选择基础、标准、品质运营标准及自管、混合、委托模式
- 办公及行政费用按“元/期”录入并按元展示月度、年度金额，系统底层自动换算为万元参与测算；招商预算仍按万元/期录入
- 物业、能耗、人员、办公、招商、营销、维保、保险等成本可勾选后一键写入地区参考值
- 筹备期成本支持快速总额和明细预算两种模式；明细预算覆盖筹备团队部门岗位、税前月薪、编制和筹备月数，物业工程/保安/保洁服务模式，行政办公和一次性开办科目
- 筹备期物业服务支持“服务类别→岗位”两级维护，物业工程、保安和保洁均可新增、删除岗位，并按岗位人数和月薪汇总服务成本
- 筹备期成本模板可分别导入筹备团队、物业服务、物业一次性费用和行政开办明细，并自动汇总到项目总投资
- 筹备期团队按岗位工资、单位社保和招聘培训核算；物业按自营、第三方常驻、第三方非常驻三种模式核算
- 物业、能耗、营销、维保、保险和其他运营费用优先按年度金额核算，系统自动反算各项权重
- 办公及行政费用、年度招商费用可逐项选择按年或按月录入，并自动换算月均和年度金额
- 渠道及代理费支持直接金额，或按“项目总建筑面积×渠道面积比例×首年月租金×佣金月数”自动计算；渠道租金单价默认带出项目均价，并可人工改写或一键恢复均价
- 人员成本继续由组织架构、月薪、薪资月数和社保公积金自动汇总
- 年度营销按营销推广、商业美陈、媒体宣传、会员营销四大类金额录入；开业首年另加导视导览和开业美陈
- 办公、招商、营销、维保和运营费用总表均显示金额、自动权重和金额来源
- 运营成本预算可下载标准 Excel 模板，填写后一次导入组织架构和各项预算
- 周边商业 POI 供给分析与竞品租金分位分析
- Excel / PPT 本地生成
- Excel、PPT 与计算引擎按需加载，降低首次打开等待
- 手机桌面安装与离线缓存

## 数据与边界

- demo 账号和演示项目只保存在当前浏览器；正式账号由 Supabase Auth 管理。
- 正式用户的项目和测算数据保存在 Supabase 云端，并受行级权限策略保护。
- 新注册的正式账号默认待审核，只有超级管理员批准后才能使用；首个正式账号自动成为超级管理员。
- 超级管理员可以查看所有正式用户、审核状态、项目摘要和最近管理记录，但不能在后台修改其他用户的项目。
- 已审核用户可向其他用户的站内收件箱发送完整项目副本，在线实时提醒、离线最长12小时内登录自动接收；分享码采用默认模型差异压缩和中文短码编码，常规项目可直接在微信单条发送；超长时仍支持分段复制和 `.ddshare.txt` 文件导入
- 行业基准覆盖购物中心、百货商场、奥特莱斯、街区商业、社区商业和社区底商
- 运营周期支持设置多个阶段性招商调整期，可分别录入起止运营年、租金调整幅度、目标出租率和一次性招商成本，并自动联动NOI、IRR和NPV
- 用户可复制项目作为方案副本，并对两个项目或方案的投资、租金、成本、NOI、IRR、NPV和回收期进行差异对比和优劣势分析
- 地图选点优先使用国内加速底图，超时或加载异常时自动切换 OpenStreetMap；正式决策仍应结合实地踏勘和授权市场数据库。
- 导入铺位后默认切换为一铺一价基准；项目页同时显示商铺建筑面积和按公区系数推算的项目总建筑面积。
- 如旧项目的主要工程单价全部为空，系统会按项目所在地和开发状态自动补充一次参考造价，避免出现不合理的极低总投资，并提示到“建设投资”复核。
- 本工具用于投资初筛与方案比较，不替代可行性研究、审计、资产评估或税务鉴证。
- 税费页提供稳定年、月均、运营期累计税费支出统计，拆分增值税销项/进项、应纳增值税、房产税、土地使用税、印花税、附加、地方基金，并分别列示融资前项目所得税和融资后股权所得税
- 租金、物业费、联营扣点等收入类税费基数按项目出租率计算；城镇土地使用税按占地面积全额计缴，不乘出租率
- 市政基础设施配套费、人防易地建设费、城镇土地使用税等应按项目属地最新政策填写。
- 建安、装修改造参考单价用于投资初筛，不替代属地造价指标、设计概算、结构鉴定或专业造价咨询。

## 本地预览

在本目录执行：

```bash
python3 -m http.server 8899
```

浏览器打开 `http://127.0.0.1:8899/`。

## 一致性审计

```bash
python3 scripts/audit_consistency.py
node --check app.js
node --check backend.js
```

每次推送和拉取请求都会由 `.github/workflows/consistency-audit.yml` 自动执行页面、计算引擎、Excel模板、单位、税费、面积和函数注解的一致性检查。
